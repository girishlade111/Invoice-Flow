# **App Name**: InvoiceFlow

## Core Features:

- Dynamic Invoice Creation: Create and manage invoice details including sender and receiver information, invoice number, and dates.
- Itemized List Management: Dynamically add, delete, and manage itemized list entries with descriptions, quantities, and rates.
- Real-time Calculations: Automatically calculate totals, subtotals, discounts, and taxes with real-time updates as values change.
- PDF Generation & Download: Generate a clean, professional PDF version of the invoice that mirrors the live preview, downloadable with a descriptive filename. A tool that determines whether all content can fit on the page.
- Print Functionality: Enable users to print the invoice directly from the browser with optimized formatting.
- Local Storage Save/Load: Allow users to save their invoice progress to local storage and load it later, enhancing usability.
- Reset Invoice: Provide a clear and easy way to reset the invoice form, clearing all fields to their default values with confirmation to avoid accidental data loss.

## Style Guidelines:

- Primary color: A professional green (#6AB38D), offering a sense of trustworthiness.
- Background color: Very light green (#F4F8F6), creating a clean and unobtrusive backdrop.
- Accent color: Teal (#439A86) used for interactive elements and highlights to draw user attention.
- Body and headline font: 'Inter', a grotesque-style sans-serif font, lends a modern, machined, objective, neutral look to the interface, suitable for both headlines and body text.
- Crisp, professional icons from Lucide Icons, enhancing usability and visual appeal.
- Two-column layout on desktop (form and live preview) and single-column on mobile for optimal responsiveness.
- Subtle transition animations to provide feedback during actions like adding items or saving the invoice.
